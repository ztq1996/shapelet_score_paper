## TQ's Writing Style

Derived from four first-author papers (arXiv:2206.10169, 2212.03257, 2507.01386, 2510.07370). Apply these traits when writing any prose for this paper.

### Language
- **Always first-person plural** ("we present", "we find", "we note") even when sole author.
- **Technical precision**: define every symbol inline on first use ("where $X$ is..."); use `\textsc{}` for software packages (e.g., `\textsc{MultiNest}`) and `\texttt{}` for code names, field names, flags, catalog columns.
- **Hedging qualifiers**: use "can", "may", "could", "likely", "potentially", "we note that", "we suspect", "we expect" when claims are not rock-solid. Always flag caveats explicitly.
- **Plain declarative findings**: state results directly — "We observe that...", "We find that...", "This suggests that...", "We conclude that..." — not buried in passive constructions.
- **"In this work"**: scope any claim that is specific to this analysis (not a general statement about the field).
- **Compound-complex sentences are fine** as long as each clause adds context (motivation, scope, or comparison), not filler.

### Paragraph Structure
- **Topic sentence first**: first sentence states the main point; the rest of the paragraph develops it.
- **Evidence before interpretation**: describe what a figure/table/test shows, then say what it means.
- **Transitional connectors**: "However,", "As a result,", "Therefore,", "In addition,", "Furthermore,", "This motivates..." to join paragraphs.
- **Caveat at the end**: a brief "We note that..." sentence typically closes a results paragraph.

### Section / Subsection Layout
- **Standard order**: Abstract → Introduction → Data → Methods → Results → Conclusion.
- **Roadmap opener for every section and subsection**: "In this section, we describe... In Section~\ref{sec:X}, we..." — even at the subsubsection level.
- **Nested subsubsections freely used** for detailed methodology breakdowns.
- **Methods summary subsection**: at the end of a long methods section, add a bullet-point summary of each approach with brief notation.
- **Introduction structure**: (1) wide-field survey landscape + cosmological relevance → (2) specific challenge or gap being addressed → (3) what this paper does → (4) paper layout as the final paragraph ("The paper is organized as follows...").
- **Conclusion structure**: short restatement of goal → bullet/numbered main findings → caveats paragraph → future work paragraph.

### Citations
- Parenthetical with context: `\citep[e.g.,][]{key1,key2}` for general support; `\citep[for a review, see][]{key}` for reviews.
- Inline narrative: `\cite{X}` or `\citet{X}` when the paper is the subject of the sentence ("In \cite{X}, the authors found...").
- Companion-paper delegation: "For further details, we refer the reader to \cite{companion}."
- First-mention acronym: `\citep[HSC SSP;][]{key}` format for survey/code abbreviations.
- Group multiple related citations: `\citep[e.g.,][]{Li2023, Dalal2023, wright2025}`.

### Describing Data
- **What → selection criteria → resulting sample size**: name the dataset, state numerical thresholds (SNR, magnitude, flags), then report the number of objects.
- **Explicit numerical cuts**: never say "high SNR galaxies" — say "$i$-band SNR $> 20$".
- **Always note limitations**: coverage gaps, depth mismatches, incomplete redshift ranges, sample variance.
- **Delegate details**: "For details of the catalog we refer the reader to \cite{ref}."

### Describing Methods
- **Motivation before math**: explain *why* the method is needed before presenting the equation.
- **Equation then inline notation**: state the equation, then define each symbol in the text immediately after ("where $\chi$ is the comoving radial distance...").
- **Software acknowledgment**: "We use the open-source \textsc{Code} \citep{ref} for...".
- **Use itemized lists** for step-by-step procedures or side-by-side algorithm comparisons.
- **Forward-reference subsections**: "as described in Section~\ref{sec:X}" rather than re-explaining.

### Describing Results
- **Figure reference precedes conclusion**: "In Fig.~\ref{fig:X}, we show..." then state the finding.
- **Quantitative**: give specific numbers ($\sigma$, fractions, percentages), not just "better/worse".
- **Comparison baseline**: always compare the new result to a reference (previous method, prior work, requirement).
- **Consistent result verbs**: "We observe...", "We find...", "We measure...", "We conclude...".

## Reference Papers

### [arXiv:2505.02928] RAIL v1: Redshift Assessment Infrastructure Layers
**Authors:** LSST DESC + LINCC Frameworks  
**Relevance:** The core software framework used for photo-z estimation in this paper.

- RAIL is an open-source Python library for end-to-end probabilistic photo-z estimation, developed by LSST DESC.
- Three subpackages: **Creation** (mock photometry generation), **Estimation** (unified API for per-galaxy and ensemble photo-z PDFs), **Evaluation** (metrics for PDFs and point estimates).
- Algorithms supported include machine learning (FlexZBoost, TPZ, KNN, DNF), template fitting (LePhare, BPZ), and hybrid methods.
- Uses `qp` for parameterizing photo-z PDFs, `tables_io` for I/O.
- Includes clustering redshift calibration via `Yet_Another_Wizz`.
- Designed for LSST but not LSST-specific; applicable to any photometric survey.

### [arXiv:2211.16516] HSC Y3 Weak Lensing Redshift Distribution Inference (Rau et al. 2022)
**Authors:** Rau, Dalal, Zhang, Li, Nishizawa, More, Mandelbaum, Miyatake, Strauss, Takada  
**Relevance:** Directly precedes this work — the HSC Y3 n(z) calibration paper; methodology and results are the baseline for the final year analysis.

- Presents posterior sample redshift distributions $p_{\rm samp}(z)$ for the HSC Y3 shape catalog (417 deg²) in four tomographic bins: (0.3, 0.6], (0.6, 0.9], (0.9, 1.2], (1.2, 1.5].
- Two complementary approaches: **photometry-based** (conditional density estimation via DNNz and DEMPz) and **cross-correlation-based** (using CAMIRA LRG sample, $z < 1.2$) in a joint Bayesian hierarchical inference.
- Key challenges addressed: photometric redshift error in CAMIRA LRGs, spatial selection function / color-redshift incompleteness of the specXphot calibration sample, and cosmic variance from spatially small calibration fields (COSMOS2015, ~2 deg²).
- Cosmic variance modeled using a Logistic Gaussian Process.
- Final recommendation: conservative shift parameter priors for the WL analysis, combining model error (dominant), cosmic variance, and statistical uncertainty. Model error from DNNz vs DEMPz differences dominates the error budget.
- Specifies that galaxies with double-peaked $p_{\rm indiv}(z)$ (secondary peak at $z > 1.2$) are excluded from the sample ("calibration cut").
- The specXphot calibration sample is assembled from: zCOSMOS, COSMOS2015, UDSz, 3D-HST, FMOS-COSMOS, VVDS, VIPERS, SDSS, GAMA, WiggleZ, DEEP2, VANDELS, C3R2, PRIMUS (~170k spec-z + ~37k prism + ~170k multiband photo-z).

### [arXiv:2511.18133] Full clustering-z calibration of HSC PDR3 with DESI (Choppin de Janvry et al. 2025)
**Authors:** Choppin de Janvry, Gontcho A Gontcho, Seljak, Baleato Lizancos, Chaussidon, d'Assignies, DeRose, Heydenreich, Paillas, Valcin, **T. Zhang** (co-author), + DESI Collaboration  
**Relevance:** The most directly relevant clustering redshift calibration predecessor — calibrates the same HSC PDR3 (Y3) shape catalog using DESI DR1+DR2, extending coverage to all four tomographic bins including $z > 1.2$. The HSC final year clustering-z calibration in this paper follows similar methodology.

- **Goal:** Full calibration of all four HSC tomographic bins ($z_p \in$ (0.3,0.6], (0.6,0.9], (0.9,1.2], (1.2,1.5]) using DESI DR1 and DR2 LSS catalogs via the clustering redshift technique.
- **Key advance over Rau+2022:** Extends calibration to Bin 3 and Bin 4 by including ELG (LOP+VLO) and QSO samples from DESI DR2 which reach $z \gtrsim 1.2$. Rau+2022 was limited to $z < 1.2$ using CAMIRA LRGs.
- **DESI tracers used:** BGS ($z \sim 0$–0.5/0.6), LRG ($z \sim 0.4$–1.1/1.2), ELG-LOP+VLO ($z \sim 0.7$–1.6, DR2 only), QSO ($z \sim 0.8$–2.8). DR1 used for Bin 1 & 2, DR2 for Bin 3 & 4.
- **Fiducial scale cut:** $0.3$–$3\, h^{-1}$Mpc. Also tested $1$–$5\, h^{-1}$Mpc for consistency.
- **Methodological innovations:**
  - Relaxes linear bias assumption to only require no redshift evolution of the cross-correlation coefficient $r(z)$, allowing use of smaller clustering scales.
  - Models bias evolution separately for the spectroscopic sample $b_s(z)$ and the photometric sample $b_p(z)$ using auto-correlation measurements.
  - Applies magnification corrections $\mu$ to the clustering signal.
  - n(z) parameterized with B-splines.
- **Calibration cut:** Same as Rau+2022 — removes sources with wide DNNz and Mizuki 95% CI ($> 2.7$) to exclude multi-modal photo-z distributions. Removes ~31% of Bin 1 and ~8% of Bin 2.
- **Key results (shifts relative to Y3 Total from Rau+2022):**
  - Bin 1: $+0.029^{+0.008}_{-0.008}$ (shifted to lower $z$)
  - Bin 2: $-0.003^{+0.009}_{-0.009}$ (consistent with Y3)
  - Bin 3: $\Delta z_3 = -0.039^{+0.020}_{-0.021}$ (shifted to higher $z$)
  - Bin 4: $\Delta z_4 = -0.048^{+0.012}_{-0.012}$ (shifted to higher $z$)
  - (Negative = higher redshift than Y3 Total by convention)
- Bins 3 & 4 shifts are smaller than those preferred by HSC Y3 cosmic shear analyses ($\Delta z_3 \sim -0.08$ to $-0.12$, $\Delta z_4 \sim -0.16$ to $-0.19$), suggesting the shear analyses may be partially absorbing residual systematics in the photo-z priors.
- Bin 3 has a high-$z$ tail ($z \sim 1.3$–1.8) with stronger amplitude than the PhotZ prediction, which was not probed in Rau+2022 due to CAMIRA LRG redshift limit.
- Code and data publicly available at `github.com/JeanCHDJdev/desi-y3-hsc`.

### [arXiv:2507.01377] Galaxy-Galaxy Lensing 2×2pt with HSC Y3 and SDSS (Zhang et al. 2025)
**Authors:** T. Zhang, S. Sugiyama, S. More, R. Mandelbaum, X. Li, R. Dalal, A. Kannawadi, H. Miyatake, A. J. Nishizawa, M. Oguri, K. Osato, M. M. Rau, M. Shirasaki, T. Sunayama, M. Takada
**Relevance:** Companion 2×2pt analysis (galaxy clustering + galaxy-galaxy lensing) using HSC Y3 + SDSS DR11; uses photo-z PDFs for optimal lens-source pair weighting in the GGL measurement. This is the "zhang et al. 2x2pt 2025" reference in this paper. Bib key: `Zhang2025_2x2pt`.

- Measures $\Delta\Sigma(R_p)$ with SDSS DR11 spectroscopic lenses and HSC Y3 shear sources in four tomographic bins, combined with $w_p(R_p)$ in a 2×2pt analysis.
- **Optimal weighting:** $w_{ls} = w_l w_s \langle\Sigma_{\rm cr}^{-1}\rangle_{\rm ls}^2$, where the per-galaxy source $p(z_s)$ PDF is integrated against $\Sigma_{\rm cr}^{-1}(z_l, z_s)$ to up-weight pairs with greater lensing geometry efficiency.
- Point-mass correction extends the small-scale cut to $R_p > 2\,h^{-1}$Mpc.
- Yields $S_8 = 0.804^{+0.051}_{-0.051}$; redshift self-calibration gives $\Delta z_3 = -0.079^{+0.074}_{-0.084}$ and $\Delta z_4 = -0.203^{+0.167}_{-0.206}$, consistent with HSC Y3 cosmic shear.

### [arXiv:2510.07370] Rubin DP1 Photo-z with RAIL (Zhang et al. 2025)
**Authors:** T. Zhang et al. (first author is the user)  
**Relevance:** Most directly analogous analysis to this paper — same pipeline (RAIL), similar reference catalog construction strategy, DESI DR1 used for validation.

- Applies 8 photo-z algorithms in RAIL to Rubin Data Preview 1 (DP1) photometry in ECDFS (6-band $ugrizy$) and SV_38_7 (4-band $griz$).
- Reference catalog built from spec-z, grism-z, and multiband photo-z from 20+ surveys (total ~22,600 objects after crossmatch), with confidence cuts ($>0.9$) and SNR cuts (i-band CModel SNR $> 20$ for training).
- Training/testing split: 70/30; training set ~6778, testing set ~2905 galaxies.
- Performance: $\sigma_{\rm NMAD} \sim 0.03$, outlier fraction ~10%, bias $< 0.005$ (meets LSST Y1 requirement) for high-SNR 6-band sample.
- DESI DR1 (BGS, LRG, ELG) used as independent validation in the SV_38_7 field.
- Euclid Q1 NIR (Y, J, H) crossmatch studied; NIR improves photo-z at $z > 1.2$.
- FlexZBoost achieves 0.78 tomographic binning accuracy.
- Dust extinction corrected using SFD maps with band-specific attenuation coefficients.
- Key caveats: training set limited to $i < 24.6$ vs catalog depth $i < 26.7$; dropout galaxies excluded by requiring detections in all bands; limited hyperparameter optimization.

### [arXiv:1704.05988] Photometric Redshifts for HSC SSP Data Release 1 (Tanaka et al. 2018)
**Authors:** Tanaka, Coupon, Hsieh, Mineo, Nishizawa, Speagle, Furusawa, Miyazaki, Murayama
**Reference:** PASJ 70, S9 (2018). Bib key: `Tanaka:2018`.
**Relevance:** The reference HSC photo-z methodology paper — origin of the $z_{\rm best}$ minimum-risk point estimate and the HSC photo-z catalog products. Cite when referring to $z_{\rm best}$.

- Computes photo-z for HSC SSP PDR1 from the five-band $grizy$ photometry using six codes: DEmP, Ephor, FRANKEN-Z, MLZ (SOMz), NNPZ (all empirical/ML), and Mizuki (template-fitting).
- **Defines the $z_{\rm best}$ point estimate**: the minimum-risk point estimate, $z_{\rm best} = {\rm argmin}\,R(z_{\rm phot})$, where the risk $R(z_{\rm phot}) = \int dz\, P(z)\, L\!\left(\frac{z_{\rm phot}-z}{1+z}\right)$ and the loss function is $L(\Delta z) = 1 - 1/[1 + (\Delta z/\gamma)^2]$ with $\gamma = 0.15$. This is the point estimate used for tomographic binning in HSC analyses.
- Also defines $z_{\rm mean}$, $z_{\rm mode}$, $z_{\rm median}$; demonstrates $z_{\rm best}$ performs best for point-estimate metrics.
- Conventional outlier definition adopted: $f_{\rm outlier} = N(|\Delta z| > 0.15)/N_{\rm total}$, with $\Delta z = (z_{\rm phot} - z_{\rm ref})/(1+z_{\rm ref})$.
- Defines a confidence parameter $C(z_{\rm phot}) = \int_{z_{\rm phot}-0.03}^{z_{\rm phot}+0.03} P(z)\,dz$ and a risk parameter (\texttt{photoz\_risk}) for outlier clipping.
- Performance is best in $0.2 \lesssim z \lesssim 1.5$; degrades at low and high $z$. No $u$-band, which limits low-$z$ (Balmer/4000\AA\ break) performance.
### [arXiv:2505.10416] Euclid: Photo-z Calibration with Clustering Redshifts in Flagship 2 (d'Assignies Doumerg et al. 2025)
**Authors:** W. d'Assignies Doumerg, M. Manera, C. Padilla, O. Ilbert, H. Hildebrandt, et al. (Euclid Collaboration)
**Bib key:** `EuclidClusterRedshifts2025`. Referred to as "William's paper" by TQ.
**Relevance:** The methodological reference this paper follows for measuring the photometric galaxy bias evolution $b_p(z)$ (Section~\ref{clustering_redshift:photo_bias}). Jean's paper (`ChoppinDeJanvry2025a`) also follows it.

- Validates the clustering-redshift technique on the Euclid Flagship 2 simulation.
- Develops the photo-$z$-spread correction for the photometric-sample auto-correlation: the photo-$z$-binned auto-correlation $w_{pp}^{\rm photo\text{-}z}$ is corrected to the true-redshift auto-correlation $w_{pp}^{\rm true}$ via a ratio of the top-hat $w_{mm}$ expectation to the $n_{p_k}(z)$-weighted $w_{mm}$ integral (the correction used in our Eq.~\ref{eq:photoz_correction}).
- Fits $\sqrt{w_{pp}^{\rm true}} = \alpha(1+z)^\beta$ (free amplitude $\alpha$, slope $\beta$), following the DES analyses (Cawthon+2022, Gatti+2018).
- Finds $\Delta z_p = 0.1$ and $\Delta z_p = 0.02$ thin bins give consistent corrections.
- Magnification correction via a "magnification matrix" $\mathcal{M}\mathbf{X}=\mathbf{n}$; $w_{mm}$ from CCL + halofit + CLASS.
